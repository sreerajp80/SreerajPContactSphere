# Change log: P2P Sync help documentation page (Settings → Help)

**Implements:** [plans/20260709_100105_p2p-sync-help-page.md](../plans/20260709_100105_p2p-sync-help-page.md)

## What changed

Added an in-app **Help** section to Settings and a documentation page explaining
the "Sync to Another Device" (P2P) feature.

### New files

- **`lib/screens/help/help_home_screen.dart`** — `HelpHomeScreen`, a Help hub that
  lists help topics. It is a hub (not a direct link to one article) so more topics
  can be added later without changing Settings again. For now it holds one topic:
  "Sync to Another Device". The topic card reuses the app's existing card style
  (accent icon + title + subtitle + chevron).

- **`lib/screens/help/p2p_sync_help_screen.dart`** — `P2PSyncHelpScreen`, the P2P
  sync documentation page. It is a scrollable article built from small private
  widgets (`_Intro`, `_Section`, `_Bullet`, `_Footer`) styled with the app's own
  theme (`AppColors`, accent color). Sections, in plain English and matching the
  real behavior in the sync services:
  - What it is (direct phone-to-phone over Wi-Fi, no internet/account).
  - Before you start (same Wi-Fi, same app version, who opens Send vs Receive).
  - How the two phones connect (pairing code + QR, code never sent, encrypted).
  - Full Sync vs Selective Sync (settings overwrite vs fill-only; Self card).
  - What gets synced (contacts + details, photos, call history, groups,
    relationships, blocked numbers, device-neutral settings).
  - What is never synced (ringtones, SIM-specific settings).
  - Nothing on the receiver is deleted (add-only merge, duplicates skipped by
    name + shared phone, and the note that skipped contacts do not bring history).
  - Privacy (local only, gated by the device lock).

### Edited files

- **`lib/screens/settings_screen.dart`** — added a **Help** card (icon
  `Icons.help_outline`, subtitle "How features like sync work") between the
  Permissions and About cards, and imported/pushed `HelpHomeScreen`.

## Not changed

No changes to services, database, models, tests, or dependencies. This is
documentation UI only.
