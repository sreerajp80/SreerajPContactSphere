# Enable SQLite WAL mode

Implements [plans/20260713_070111_enable-wal-mode.md](../plans/20260713_070111_enable-wal-mode.md).

## What changed

- `lib/database/database_helper.dart`: added `PRAGMA journal_mode = WAL` to
  `_onConfigure`, alongside the existing `PRAGMA foreign_keys = ON`. This puts
  the SQLite database into Write-Ahead Logging mode, as required by engineering
  standard §13.2.
- Updated the `_onConfigure` doc comment to describe the WAL behaviour.

## Why

Before this change the DB ran in the default `delete` rollback-journal mode,
which serialises readers and the writer. WAL allows concurrent readers with a
single writer, improving performance under typical app workloads.

## Notes

- One hook covers both open paths — plain sqflite (tests / non-Android) and the
  SQLCipher on-device path — because both pass `onConfigure: _onConfigure`.
- WAL persists in the DB file header; `_onConfigure` runs per connection so it
  is safely reapplied on every open.
- Expect `-wal` / `-shm` sidecar files next to the DB file at runtime; this is
  normal for WAL mode.
