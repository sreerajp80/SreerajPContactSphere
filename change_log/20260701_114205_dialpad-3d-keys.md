# Bordered, 3D dialpad keys (light + dark)

Implements [plans/20260701_113459_dialpad-3d-keys.md](../plans/20260701_113459_dialpad-3d-keys.md).

Gave the dialer keypad buttons a border and a raised 3D look that adapts to both the Calm
(light) and Midnight (dark) themes.

## Changes

### `lib/screens/dialer_screen.dart`
- **`_key`** — each key is now a raised, bordered tile instead of a transparent `InkWell`:
  - Fill: `colors.cardSurface`; corners rounded (radius 18).
  - Border: 1px, theme-aware — black @ 0.10 alpha on light, white @ 0.10 alpha on dark.
  - 3D shadow: a soft drop shadow (black @ 0.14 light / 0.45 dark, blur 8, y-offset 3) for
    the raised feel, plus a faint white top-highlight bevel on light only (it reads poorly
    on the dark surface).
  - `InkWell` sits on top (clipped to the rounded rect) so tap ripple + long-press-`0`-for-`+`
    behavior are unchanged. Digit size trimmed 28 → 26 to sit comfortably in the tile.
- **`_dialpad`** — widened spacing for the now-visible tiles (`mainAxisSpacing` 4 → 10,
  horizontal padding 28 → 24) and set `childAspectRatio` 1.6 → 1.5 so tiles aren't too flat.

## Out of scope
- The main call button (already gradient + drop shadow, i.e. already 3D).

## Verification
- `flutter analyze` — No issues found.
- Purely presentational; no logic changed and tests don't assert key styling.

## Notes
- Press feedback stays as the ink ripple; no animated push-down depth change (can be added
  later if a stronger tactile effect is wanted).
