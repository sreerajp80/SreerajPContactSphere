# Dialer Screen Redesign + Favorites feature

Implements [plans/20260701_094532_dialer-redesign.md](../plans/20260701_094532_dialer-redesign.md).

Restyled the Dialer to the new mockup in `sample/DialerScreen.dc.html` and added a real
"favorites" feature to back the design's empty-state Favorites list. The number is shown
raw (no US-style grouping), per the agreed decision.

## Changes

### Data layer — favorites
- **`lib/database/database_helper.dart`**
  - Bumped DB `version` 7 → 8.
  - Added `is_favorite INTEGER DEFAULT 0` to the `contacts` table.
  - Added a `v7 → v8` migration (`ALTER TABLE contacts ADD COLUMN is_favorite …`) and an
    `idx_contacts_is_favorite` index (created in `_createIndexes` and in the v8 branch).
- **`lib/models/contact.dart`** — added the `bool isFavorite` field (default `false`),
  wired into the constructor, `toMap` (`is_favorite`), and `fromMap`.
- **`lib/repositories/contact_repository.dart`**
  - `PhoneMatch` gained a nullable `label`; `findByPhoneFragment` now selects `p.label` so
    suggestion rows can render "Label · number".
  - Added `getFavoriteMatches({limit})` — starred, non-secret contacts with their primary
    phone + label (favorites without a phone are returned with an empty number).
  - Added `setFavorite(contactId, value)`.

### Add/Edit — "Add to contacts" prefill
- **`lib/screens/add_edit_contact_screen.dart`** — added an optional `initialNumber`
  constructor param; when creating a new contact it seeds the first phone field (label
  "Mobile", primary) with that number. The "Add contact" title and insert-vs-update logic
  are unaffected.

### Contact detail — mark a favorite
- **`lib/screens/contact_detail_screen.dart`** — added a star toggle to the app bar
  (`Icons.star` / `Icons.star_border`) that optimistically flips `contact.isFavorite` and
  persists via `setFavorite`, reverting with a SnackBar on failure.

### Dialer screen — the redesign
- **`lib/screens/dialer_screen.dart`** — rebuilt the layout:
  - Top app bar: "Dialer" title + a round "More" button (`PopupMenuButton` → Settings).
  - Number display moved to the top: centered, large, raw digits, with an inline backspace;
    shows "Start typing to find a contact" when empty.
  - Scrollable middle strip: Favorites (circle avatars) when empty, "N match(es)" with rows
    (rounded-square avatars, "Label · number") while typing, and an "Add to contacts" card
    plus a muted note when nothing matches.
  - Row gestures: tap = select/fill the number (a phone-less favorite opens the contact
    instead); accent call button = place the call directly; long-press = open the contact.
  - Keypad keys now show an accent-tinted pressed background; long-press `0` still types `+`.
  - Call row: gradient call button centered (long-press = clear) with a backspace to its right.
  - Favorites are loaded on init and refreshed after returning from a contact or adding one.

## Verification
- `flutter analyze` — No issues found.
- `flutter test` — all 27 tests pass (including the contact-sync/repository suite that
  exercises the changed schema and `PhoneMatch`).
