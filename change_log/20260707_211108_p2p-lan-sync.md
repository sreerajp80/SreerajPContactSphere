# Change log: P2P LAN sync (whole-app device clone)

Implements `plans/20260707_211108_p2p-lan-sync.md`.

## What this adds

A new feature to copy **everything** in ContactSphere from one phone to another
phone running the same app, over the local Wi-Fi, with no server and no internet.
It is a **mirror / full-replace** clone: the source phone hosts and pushes its
whole database; the new phone wipes its own data and reloads the sender's,
keeping every row id so all links (relationships, groups, call logs, …) stay
consistent.

Security is ported from the SMS Sentry `P2PSyncEngine` guide: a fresh ~320-bit
pairing code is shown on the host and typed on the client — it never crosses the
socket. The payload is AES-GCM sealed with a key derived from that code
(PBKDF2-HMAC-SHA256, 120k iterations). A wrong code derives a wrong key and
decryption fails, which is the authentication. No fallback cipher.

## Files created

- `lib/services/p2p_sync_service.dart` — the engine: crypto block (pairing-code
  generation/normalization, PBKDF2 key derivation, AES-GCM encrypt/decrypt),
  host server + client over a `dart:io` socket (port 8243), a bounded newline
  reader with a 30 s read timeout, local-IPv4 discovery, and a `ChangeNotifier`
  `SyncState` (Idle / Hosting / Connecting / InProgress / Completed / Error).
  Exposes `@visibleForTesting` `debugEncrypt`/`debugDecrypt` hooks.
- `lib/services/sync_bundle_service.dart` — the app-specific half:
  `exportBundle` dumps every synced table (ids included) + device-neutral
  settings + photo/calling-card file bytes into a META JSON + media frames;
  `applyBundle` validates caps, writes media into app storage, then wipes and
  reloads every table in one transaction (FK enforcement toggled off around it),
  and restores settings. Includes the schema-version guard.
- `lib/screens/p2p_sync_screen.dart` — Send / Receive UI (host shows IP + grouped
  code with copy; client types IP + code behind a "this replaces everything"
  confirmation), driven by the `SyncState`.
- `test/p2p_crypto_test.dart` — pairing-code + encrypt/decrypt round-trip and the
  wrong-code / wrong-salt failure guarantees (8 tests, pass).
- `test/p2p_bundle_test.dart` — export → apply DB round-trip (ids intact, secret
  contact preserved, `device_id` cleared, historical SIM label kept), settings
  restore, SIM-key exclusion, schema-mismatch refusal, and the field-size cap
  (4 tests, pass). Run on its own (SQLite native-asset one-file-per-invocation).

## Files changed

- `pubspec.yaml` — added `cryptography: ^2.9.0` (Dart has no built-in AES-GCM).
- `android/app/src/main/AndroidManifest.xml` — added `INTERNET`,
  `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE`, `CHANGE_WIFI_STATE` (the app was
  fully offline before this).
- `lib/screens/settings_screen.dart` — new "Transfer to another phone" card that
  opens the sync screen behind an `AuthService` biometric check (the payload
  includes secret contacts).
- `docs/architecture.md`, `docs/known-gaps.md` — documented the feature.

## Deliberate design choices

- **Not copied** (device-specific / harmful on another phone): `contacts.device_id`
  and `merged_device_ids` (source-phone address-book links — cleared so the new
  phone re-links on its own device sync); SIM-account-keyed settings
  (`default_sim_id`, per-SIM ringtones/colors); ringtone audio (only the path
  travels — the tone is kept only if a file already exists at that path).
- **SIM mismatch (e.g. 2-SIM source → 1-SIM destination):** safe. Because the SIM
  *preferences* are not synced, the destination keeps its own SIM setup and never
  gets a default SIM pointing at a SIM it lacks. Historical `call_logs` SIM labels
  do copy but are display-only in Recents and never place a call. Decision:
  kept as honest history.
- **Secret contacts are included** (the whole point is a full copy), which is why
  the flow is gated behind biometric auth.

## Out of scope (as agreed)

Merge mode (keeping the receiver's own data), two-way sync, and mDNS/NSD
auto-discovery. This version is one-way, full-replace, manual-IP.

## Verification

`flutter analyze` — no issues. `flutter test test/p2p_crypto_test.dart` — 8/8
pass. `flutter test test/p2p_bundle_test.dart` — 4/4 pass. The live socket
transfer between two phones and the photo/calling-card media round-trip are
verified manually on devices (the host VM has no LAN peer or `path_provider`).
