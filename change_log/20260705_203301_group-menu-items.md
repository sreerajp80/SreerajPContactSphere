# Grouped overflow-menu items: "Import / Export" and "Bluetooth transfer"

Implements plan: `plans/20260705_202932_group-menu-items.md`

## What changed

Only one file: `lib/screens/contact_list_screen.dart`.

1. **Menu (in `_buildHeader`):** the four CSV/vCard items (Import CSV, Export CSV,
   Import vCard, Export vCard) were replaced by one "Import / Export" item, and the
   two Bluetooth items (Send all, Receive) by one "Bluetooth transfer" item. The
   menu went from 10 items to 7: My Profile, Import / Export, Bluetooth transfer,
   Scan QR code, Find Duplicates, divider, Settings.

2. **Handler (in `_handleMenu`):** two new cases, `'import_export'` and
   `'bluetooth'`. Each opens a chooser bottom sheet; the picked value is fed back
   into `_handleMenu`, so the original action cases (`'import'`, `'export'`,
   `'import_vcf'`, `'export_vcf'`, `'send_all_ble'`, `'receive_ble'`) run
   unchanged. A `mounted` check guards the re-dispatch after the sheet closes.

3. **New helper `_showActionSheet`:** shows a bottom sheet in the app's standard
   style (drag handle, bold title, icon + label `ListTile` rows) and returns the
   picked option's value. Style copied from the existing call-history action
   sheet. Sheet labels stay explicit ("Import CSV", "Export CSV", ...) so import
   and export cannot be mixed up.

## Verification

- `flutter test` — all 80 tests passed.
