# Change log — Flutter 3.41.9 / Dart 3.11.5 upgrade

Date: 2026-06-25 08:03:32 (local)
Implements plan: `plans/20260625_075628_flutter-3.41-upgrade.md`

## What changed

### `pubspec.yaml`
- `environment.sdk`: `'^3.8.0'` → `'^3.11.0'` (match installed Dart 3.11.5).
- Direct dependency constraints re-resolved against the SDK via
  `flutter pub upgrade --major-versions`. Major bumps:
  - `share_plus`: `^11.0.0` → `^13.1.0`
  - `csv`: `^6.0.0` → `^8.0.0`
  - `flutter_local_notifications`: `^19.3.0` → `^22.0.1`
  - `timezone`: `^0.10.1` → `^0.11.0`
  - `flutter_contacts`: `^1.1.7` → `^2.1.0`
  - `flutter_blue_plus`: `^1.31.4` → `^2.3.9`
  - `local_auth`: `^2.1.7` → `^3.0.1`
  - (Other deps stayed at their constraints but resolve to latest-in-range in
    `pubspec.lock`; `path_provider`, `shared_preferences`, `provider`, `image_picker`,
    `geolocator` etc.)
- `pubspec.lock` regenerated.

### `lib/main.dart`
- `ThemeData(cardTheme: CardTheme(...))` → `CardThemeData(...)`. In Flutter 3.41
  `ThemeData.cardTheme` is typed `CardThemeData`; the old form is now a compile error.
  This was the only version-driven compile break in existing code.

## Verification
- `flutter pub get` resolves cleanly on SDK 3.11.5.
- `flutter analyze`: 57 issues remain — **all pre-existing**, none introduced by the
  upgrade. They fall into:
  - Missing files/classes/imports that are the subject of the build-out plan
    (`permission_service`, `Address`, `OfficialDetails`, `CallSummary`, model imports,
    `file_picker`, the counter-template test).
  - `flutter_lints` / `flutter_test` "not found" — these dev_dependencies are added in
    build-out Phase 0.
  The `CardTheme` error is **gone**; `main.dart` now only reports the missing
  `permission_service` import.

## Follow-on API migrations surfaced by the major bumps (for the build-out)
These do not break anything today (the affected files don't compile yet) but the
build-out must target the new APIs:
- **csv 8.0.0** is a breaking rewrite: `ListToCsvConverter` / `CsvToListConverter` are
  removed. Use the new `Csv` codec (`csv.encode(rows)` / `csv.decode(text)`).
  Affects `lib/services/export_import_service.dart`.
- **share_plus 13** deprecates `Share.share(...)` → use
  `SharePlus.instance.share(ShareParams(...))`. Affects `export_import_service.dart`.
- **flutter_blue_plus 2.x, local_auth 3.x, flutter_local_notifications 22.x,
  flutter_contacts 2.x** all carry API changes vs. the old constraints. None are used
  in current code; relevant only when/if those features are implemented (most are
  out of scope for the build-out).

## Known risks noted (not addressed here)
- `qr_code_scanner: ^1.0.1` is discontinued and known to break newer Android Gradle
  builds via the old plugin embedding. It resolved in `pub get` and is unused in code,
  but may surface at `flutter build apk` time. If QR is ever implemented, migrate to
  `mobile_scanner`. (QR is out of scope for the current build-out.)
