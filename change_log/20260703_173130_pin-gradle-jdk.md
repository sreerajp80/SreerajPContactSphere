# Pin Gradle JDK to Android Studio JBR

Implements [plans/20260703_173130_pin-gradle-jdk.md](../plans/20260703_173130_pin-gradle-jdk.md).

## What changed

- `android/gradle.properties` — added `org.gradle.java.home=E:/Android/Android Studio/jbr`
  (with an explanatory comment) so all Gradle invocations run on the Android Studio
  bundled JBR (JDK 21) instead of the machine's `JAVA_HOME` (JDK 24).

## Why

Direct `gradlew` runs used `JAVA_HOME` = JDK 24, which Gradle 8.12 (max Java 23) and
AGP 8.9.1 (qualified up to JDK 21) do not support. AGP crashed at configuration time
with `java.lang.TypeNotPresentException: Type T not present` while creating the
`AndroidUnitTest` component for `:audioplayers_android` — before any project code
compiled. Pinning the JDK removes the unsupported combination.

## Verification

- `.\gradlew :app:tasks` from `android/` — configuration completes; all
  `test<Variant>UnitTest` tasks (the previously crashing component) are listed.
- `flutter build apk --debug --flavor dev` — builds successfully
  (`app-dev-debug.apk` produced).
