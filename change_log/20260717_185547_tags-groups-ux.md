# Tags & Groups UX improvements — change log

Implements plan `plans/20260717_164653_tags-groups-ux.md`.

## Feature 1 — Tags are now case-insensitive

File: `lib/screens/add_edit_contact_screen.dart`

- `_addTag` now dedupes ignoring case, so "family" and "Family" can no longer
  both be added. When the typed tag matches a known tag (from `_allTags`) in a
  different case, the stored casing is reused so there is one canonical spelling.
- The tag suggestion filter now still shows an existing tag when its name is
  typed in a different case (e.g. typing "family" shows the existing "Family"
  as a selectable suggestion). Only an exact same-casing match is hidden.

## Feature 2 — Groups use a search box (like tags)

File: `lib/screens/add_edit_contact_screen.dart`

- Added a `_groupInput` text controller (created, listened, and disposed
  alongside `_tagInput`).
- Rewrote `_groupsSection`: instead of listing every group as a chip, it now
  shows selected groups as removable chips, a search field ("Search or create a
  group") with an add button, and case-insensitive suggestions of unselected
  groups below.
- `_addGroup` now takes an optional value (from a suggestion, the add button, or
  the enter key) instead of opening a dialog. It selects an existing group
  (case-insensitive) or creates a new one — the same select-or-create behaviour
  as tags.
- Removed the now-unused `_promptText` dialog helper.
- Saving is unchanged: `contact.groups` is still built from the selected chips.

## Feature 3 — Add contacts to a group from the Groups page

File: `lib/repositories/group_repository.dart`

- Added `contactIdsInGroup(int groupId)` returning the set of member contact ids,
  used to pre-check existing members in the picker.

File: `lib/screens/groups_screen.dart`

- Added an "Add contacts…" action to each group's popup menu.
- Added `_addContactsToGroup(Group)`: loads all contacts and current members,
  opens a multi-select picker, then adds only the newly-checked contacts via the
  existing `addContactToGroup` (duplicates ignored), refreshes the list, and
  shows a snackbar with the count added.
- Added a private `_ContactMultiPickerSheet` widget: a searchable, checkable
  bottom-sheet list of contacts. Search mirrors the Contacts page (lowercase
  substring plus transliteration-key match). Contacts already in the group are
  shown checked and locked (removal is still done from the contact editor).

## Verification

- `flutter analyze` on the three changed files: **No issues found.**
- No database schema or migration changes.

## Manual checks recommended (on device)

- Type an existing tag in a different case → it appears as a suggestion and,
  when added, keeps the stored casing; no duplicate is created.
- Groups field in the contact editor: typing filters the group list; select an
  existing group or create a new one; remove a selected group with its "x".
- Groups page → group menu → Add contacts… → search, multi-select, Add →
  contacts are added and the member count updates.
