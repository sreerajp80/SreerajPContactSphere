# Change log: bigger save tick button

Implements [plans/20260717_193000_bigger-save-tick.md](../plans/20260717_093000_bigger-save-tick.md).

## What changed
In [lib/screens/add_edit_contact_screen.dart](../lib/screens/add_edit_contact_screen.dart):

1. `_circleIconButton()` gained two optional params, `size` (default 40) and
   `iconSize` (default 22). The `SizedBox` and `Icon` now use them. Defaults keep
   the back button unchanged.
2. In `_topBar()`, the save tick (`Icons.check`) now passes `size: 48,
   iconSize: 26`, making only the save button bigger.

## Result
The top-bar save tick on the add/edit contact screen is larger and easier to tap;
the back button is untouched.
