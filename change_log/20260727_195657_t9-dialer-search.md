# Change Log - T9 Smart Dialing Search Implementation

- **Date**: 2026-07-27
- **Plan Reference**: [plans/20260727_195506_t9-dialer-search.md](../plans/20260727_195506_t9-dialer-search.md)

## Summary of Changes
Implemented dual T9 Smart Dialing (letter-to-digit contact name search) alongside existing phone number fragment matching on the dialpad.

### 1. `lib/utils/t9_utils.dart` [NEW]
- Added `T9Utils` helper class to map keypad letters (2-9) to digits.
- Implemented `isT9Match()` supporting English and transliterated Malayalam names via `MalayalamTransliterator` / `searchKey`.
- Implemented `scoreMatch()` to prioritize results:
  1. Contact name word-prefix match (score 100/95)
  2. Phone number prefix match (score 85)
  3. Contact name / phone number substring match (score 65/45)

### 2. `lib/repositories/contact_repository.dart` [MODIFY]
- Updated `findByPhoneFragment()` to score candidate contacts using `T9Utils.scoreMatch()`.
- Returns deduplicated, rank-sorted `PhoneMatch` suggestions to `DialerScreen`.

### 3. `test/t9_utils_test.dart` [NEW]
- Added unit tests for letter conversion, word-prefix T9 matching, Malayalam transliteration matching, and score-based match ordering.

- Unit Tests: `flutter test test/t9_utils_test.dart` passed 100%.
