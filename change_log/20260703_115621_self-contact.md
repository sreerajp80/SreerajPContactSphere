# Change log: "Self" contact (phone owner), pinned first in the list

Implements [plans/20260703_114453_self-contact.md](../plans/20260703_114453_self-contact.md).

## What changed

Added a **Self** contact concept — the details of the person using the phone — represented
as a new `is_self` flag on `contacts`. The Self contact is an ordinary contact aggregate plus
this flag; it is pinned to the top of the contact list irrespective of sort order, is a
singleton, and is app-only (never written to the device address book).

### Database (`lib/database/database_helper.dart`)
- Bumped DB `version` 10 → **11**.
- Added `is_self INTEGER DEFAULT 0` to the `contacts` table in `_onCreate`.
- Added a `v10 -> v11` migration (`ALTER TABLE contacts ADD COLUMN is_self ...`) plus a new
  `idx_contacts_is_self` index (added to both `_createIndexes` and the migration).

### Model (`lib/models/contact.dart`)
- Added `bool isSelf` (default `false`): constructor param, `toMap` (`'is_self'`), `fromMap`.

### Repository (`lib/repositories/contact_repository.dart`)
- Added `c.is_self` to the shared `_summarySelect` projection.
- `getContactSummaries` and `countContacts`: now **exclude** Self (`is_self = 0`) so it never
  affects offset paging; both stay consistent with each other.
- `averageRelationshipScore`: excludes Self (its score is meaningless).
- `searchContactSummaries`: **includes** Self and orders `c.is_self DESC, c.first_name ASC`
  so a matching Self sorts first.
- `getAllContacts`: orders `is_self DESC, first_name ASC` (first-run merged read).
- New `getSelfSummary()` (slim) and `getSelfContact()` (hydrated) → `Contact?`.
- Singleton enforcement: `insertContact`/`updateContact` call a new `_clearOtherSelf(txn, id)`
  inside the transaction when the saved contact is Self.
- `findDuplicates` / `findDuplicateGroups`: wrapped the candidate `WHERE` with
  `c.is_self = 0 AND (...)` so Self is never offered for merge.

### Sync service (`lib/services/contact_sync_service.dart`)
- New `selfSummary()` / `selfContact()` passthroughs.
- `saveContact`: Self is now app-only, sharing the secret branch (`c.isSecret || c.isSelf`) —
  cleared `device_id`, and any previous device link is deleted.
- `mergedContacts`: sort comparator pins Self first, then by first name.

### Add/Edit screen (`lib/screens/add_edit_contact_screen.dart`)
- New `initialIsSelf` constructor param (default `false`).
- `_isSelf` state, initialized from `widget.contact?.isSelf ?? widget.initialIsSelf`; written
  to the contact on `_save`.
- New `_selfSection()` toggle ("This is me" / "Your own details — pinned to the top"), styled
  like the existing Secret toggle, placed just above the secret section.

### Contact list screen (`lib/screens/contact_list_screen.dart`)
- New `Contact? _self` state loaded via `_loadSelf()` in `_reload` (best-effort, cleared on
  error).
- `_buildList` renders the Self card first when the list is unfiltered (`_searchQuery.isEmpty
  && _self != null`); index math updated for the optional leading card alongside the trailing
  paging spinner.
- `_buildContactCard` shows a filled **"YOU"** pill (in place of the first-group chip) for the
  Self contact.
- Added a **"My Profile"** overflow menu item + `_openSelf()`: opens the Self contact's detail
  if set, else opens `AddEditContactScreen(initialIsSelf: true)` to create it.

## Verification
- `flutter analyze` — **clean** (no issues).
- `flutter test` — 42/43 pass. The one failure (`widget_test.dart` → "renders the home shell")
  is **pre-existing and unrelated**: it asserts a Material `NavigationBar`, but `home_shell.dart`
  intentionally uses a custom bottom bar (documented in its own comments), so `NavigationBar`
  appears nowhere in `lib/`. This change does not touch `main.dart` or `home_shell.dart`.

## Follow-ups / out of scope

- No link to the device OS "Me/profile" contact (Self is app-managed).
