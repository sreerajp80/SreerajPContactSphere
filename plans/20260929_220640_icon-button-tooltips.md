## Issue

Engineering standard §7.8 says every icon-only button MUST have a tooltip, and the text MUST come
from the ARB files. The audit found:

- 16 icon-only controls with no tooltip at all.
- 4 tooltips that are English literals (3 in `relationship_screen.dart`, 1 in
  `ble_receive_screen.dart`), so they stay English under Malayalam and Sanskrit.
- Only one test (`blocked_numbers_screen_l10n_test.dart`) checks a tooltip, so nothing stops a new
  button without one.

## Plan

| `contact_detail_screen.dart` | call button on a number row | `tooltipCall` (existing) |
| `contact_index_health_screen.dart` | refresh | `tooltipCheckAgain` (new) |
| `groups_screen.dart` | FAB | `tooltipCreateGroup` (new) |
| `groups_screen.dart` | per-group menu | `tooltipMore` (existing) |
| `relationship_screen.dart` | sheet close | `actionClose` (existing) |
| `relationship_screen.dart` | "Centre sphere here" literal | `tooltipCentreSphere` (new) |
| `relationship_screen.dart` | "Open profile" literal | `tooltipOpenProfile` (new) |
| `relationship_screen.dart` | "Options" literal | `tooltipMore` (existing) |

### 2. New ARB keys (all three files, with a description in the template)

| Key | English | Malayalam | Sanskrit |
|---|---|---|---|
| `tooltipCheckAgain` | Check again | വീണ്ടും പരിശോധിക്കുക | पुनः परीक्ष्यताम् |
| `tooltipCreateGroup` | Create group | ഗ്രൂപ്പ് സൃഷ്ടിക്കുക | समूहः सृज्यताम् |
| `tooltipCentreSphere` | Centre sphere here | ഇവിടെ കേന്ദ്രീകരിക്കുക | अत्र केन्द्रीक्रियताम् |
| `tooltipOpenProfile` | Open profile | പ്രൊഫൈൽ തുറക്കുക | परिचयः उद्घाट्यताम् |
| `tooltipCancelRedial` | Cancel redial | വീണ്ടും വിളി റദ്ദാക്കുക | पुनराह्वानं निरस्यताम् |
| `tooltipScanAgain` | Scan again | വീണ്ടും തിരയുക | पुनः अन्विष्यताम् |
| `tooltipShowPassword` | Show password | പാസ്‌വേഡ് കാണിക്കുക | गुप्तशब्दः दर्श्यताम् |
| `tooltipHidePassword` | Hide password | പാസ്‌വേഡ് മറയ്ക്കുക | गुप्तशब्दः गोप्यताम् |
| `tooltipRemoveAccount` | Remove account | അക്കൗണ്ട് നീക്കുക | उपयोक्तृविवरणम् अपनीयताम् |

The terms follow the §8.5.4 glossary (Open, Cancel, Create, Search, Remove) and the words the app
already uses (Profile, Account, Password, redial). Sanskrit uses the polite `-ताम्` imperative for
buttons. They will be listed in the change log as "needs native-reader review" (§8.5.4 review rule).
All fit the 22-character budget; the existing label-length test checks this.

Then run `flutter gen-l10n`.

### 3. Tests

- `test/helpers/tooltip_checks.dart`: the `expectAllIconButtonsHaveTooltips` helper from standard
  §7.8 (checks every `IconButton` and `FloatingActionButton` on screen), plus `PopupMenuButton`.
- Call the helper in the existing screen tests under `test/l10n/` and `test/screens/`, which already
  pump screens in all three languages.
- `test/l10n/icon_tooltip_source_test.dart`: reads every `.dart` file under `lib/` and fails when an
  `IconButton`, `FloatingActionButton` or `PopupMenuButton` has no `tooltip:`, or when a `tooltip:` is
  a string literal. This covers screens that have no widget test yet, so a new button without a
  tooltip fails the build.

### 4. Check

- `flutter analyze` (zero issues), `dart format` on changed files.
- `flutter test test/l10n test/screens test/state`, and the other test files that touch the changed
  screens, one file per run where they use SQLite.
