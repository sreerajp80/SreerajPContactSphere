# Make the save tick button bigger

**Status:** completed

## Issue
On the add/edit contact screen, the top-bar save button (the tick / `Icons.check`)
is small. The user wants it a little bigger so it is easier to see and tap.

## Where it lives
- [lib/screens/add_edit_contact_screen.dart](lib/screens/add_edit_contact_screen.dart)
  - `_topBar()` (around line 1143) builds the tick with `_circleIconButton(icon: Icons.check, ...)`.
  - `_circleIconButton()` (around line 1177) is a shared helper with a fixed 40x40
    circle and a 22px icon. The back button uses the same helper, so I must not
    change the shared default — only the tick should grow.

## Files to change
- `lib/screens/add_edit_contact_screen.dart`

## Fix
1. Add two optional params to `_circleIconButton`: `double size = 40` and
   `double iconSize = 22`. Use them for the `SizedBox` width/height and the
   `Icon` size. Defaults keep the back button unchanged.
2. In `_topBar()`, pass a bigger size for the tick button, e.g. `size: 48,
   iconSize: 26`. This makes only the save tick larger.

## Verify
- `flutter analyze` stays clean for this file.
- Visually: the back button is unchanged; the tick is noticeably bigger.
