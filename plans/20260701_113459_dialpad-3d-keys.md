# Bordered, 3D dialpad keys (light + dark)

**Status:** completed

## Request

Give the dialer keypad buttons a **border** and a **3D (raised) effect**, working in **both
light and dark** themes. (Reference: the user's screenshot of the current flat, borderless
keypad.)

## What is there now

In [dialer_screen.dart](../lib/screens/dialer_screen.dart), each key (`_key`) is a
transparent `InkWell` in a `GridView.count` (`_dialpad`) — just the digit + letters, no
background, border, or elevation. `childAspectRatio` is `1.6` (cells are wider than tall).

## The plan

Turn each key into a **raised, bordered tile** while keeping the digit + letters layout and
the existing tap / long-press-`0`-for-`+` behavior.

Per key (`_key`):
- Wrap the content in a `Container` with:
  - **Fill:** `colors.cardSurface` (white in light, dark surface in dark) so the tile reads
    as a distinct raised surface against the scaffold background.
  - **Border:** 1px. Light: subtle dark border (`ink`/black at low alpha ~0.10). Dark:
    white at low alpha (~0.10). Derived from `colors.isDark`.
  - **Rounded corners:** radius ~18 (rounded-square, fits the `1.6` cell without going
    circular).
  - **3D shadow:** a soft drop shadow below for the raised feel —
    - Light: dark shadow (`Colors.black` ~0.14 alpha, small blur, y-offset ~3) **plus** a
      faint top highlight (white) for a subtle neumorphic bevel.
    - Dark: a deeper black shadow (higher alpha) since a white highlight reads poorly on the
      dark surface; keep just the drop shadow.
- **Pressed state:** keep feedback tactile — the `InkWell` splash/highlight stays; the tile
  visually "presses" by using `InkWell` on top of the container (ripple clipped to the
  rounded rect). (No animated depth change planned — kept simple; can add later if wanted.)
- Adjust `_dialpad` spacing so the now-visible tiles have breathing room: bump
  `mainAxisSpacing`/`crossAxisSpacing` (e.g. 10 / 12) and tune `childAspectRatio` a touch
  (~1.5) so tiles aren't too flat. Keep the pad within its current vertical space.

Colors are all pulled from the existing `AppColors` tokens + `colorScheme`, so light and
dark both get an appropriate border/shadow automatically.
