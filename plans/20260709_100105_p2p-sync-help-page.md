# Plan: P2P Sync help documentation page (Settings → Help)

**Status:** completed

## What the user wants

Write user-facing documentation for the P2P ("Sync to Another Device") feature and
show it inside the app as a page reached from **Settings → Help**.

## The issue / gap

- Settings has cards for Contacts, Sync, SIM, Ringtone, Appearance, Permissions and
  About, but there is **no Help section at all** (see
  [lib/screens/settings_screen.dart](../lib/screens/settings_screen.dart)).
- The sync feature is non-trivial (Full vs Selective sync, add-only merge, what is and
  is not synced, the pairing-code security model) and nothing in the app explains it to
  the user. All of that knowledge currently lives only in code comments and the plans.

## Design decision

Add a small **Help hub** rather than wiring the Help card straight to one document, so
more help topics can be added later without re-touching Settings. For now the hub lists
a single topic: **Sync to Another Device (P2P Sync)**.

Structure:
- Settings → new **Help** card → `HelpHomeScreen` (list of help topics)
- `HelpHomeScreen` → **Sync to Another Device** topic → `P2PSyncHelpScreen`
  (the documentation page)

The documentation content is derived from the actual behavior in
[lib/services/sync_bundle_service.dart](../lib/services/sync_bundle_service.dart) and
[lib/services/p2p_sync_service.dart](../lib/services/p2p_sync_service.dart), so it stays
accurate.

## Files to change

1. **New:** `lib/screens/help/help_home_screen.dart`
   - A `HelpHomeScreen` that mirrors the existing Settings card style (reuse the same
     `Card` + `InkWell` + accent-icon row look used in `sync_home_screen.dart`).
   - Lists help topics; first (only) entry: "Sync to Another Device" → opens
     `P2PSyncHelpScreen`.

2. **New:** `lib/screens/help/p2p_sync_help_screen.dart`
   - The P2P sync documentation page: a scrollable article built from styled section
     blocks (section heading + body text + bullet lists), using the app's theme
     (`AppColors`, accent color) so it matches the app's own design — not a generic look.
   - Small private helper widgets in the same file (`_Section`, `_Bullet`) to keep the
     content readable. No new shared components.

3. **Edit:** `lib/screens/settings_screen.dart`
   - Add a **Help** card (icon `Icons.help_outline`, title "Help", subtitle e.g.
     "How features like sync work") between **Permissions** and **About**.
   - Import and push `HelpHomeScreen`.

No changes to services, database, or tests (this is documentation UI only). No new
dependencies.

## Documentation content (what the P2P page will say, in simple English)

Sections, each written plainly and matching real behavior:

1. **What it is** — Copy your contacts (and more) from one phone to another over the
   same Wi-Fi, with no internet or account. Both phones must run this app.
2. **Before you start** — Same Wi-Fi network; both phones on the same app version
   (a version mismatch is refused with a clear message); the sender opens
   "Send", the receiver opens "Receive".
3. **How to connect** — Sender shows a pairing code + QR; receiver scans the QR or types
   the code. The code is shown on screen only and never sent over the network; the whole
   transfer is encrypted, so a wrong code simply fails.
4. **Full Sync vs Selective Sync**
   - Full Sync: sends everything (all categories) and the sender's settings overwrite
     the receiver's; the sender's own "Self" card comes across as a normal contact.
   - Selective Sync: sends only the categories you pick (contacts are always included);
     settings only fill in blanks and the Self card is not sent.
5. **What gets synced** — Contacts and their details (phone numbers, emails, addresses,
   official details, social links, tags), contact photos and calling-card photos, call
   history (call logs, interactions, reminders), groups, relationships, blocked numbers,
   and app settings (theme, accent color, default country, and other device-neutral
   options).
6. **What is NOT synced** — Ringtones and per-SIM settings (default SIM, per-SIM
   ringtones/colors), because those point at things specific to the sender's phone.
7. **Nothing is deleted (add-only merge)** — The receiver keeps all of its own data.
   A contact you already have (same name and a shared phone number) is skipped, not
   duplicated or overwritten. Only brand-new contacts are added, and their details and
   call history come with them. Note: if a contact already exists and is skipped, the
   sender's call history for that contact is not merged in.
8. **Your data stays private** — Everything is peer-to-peer over your local Wi-Fi;
   nothing goes to the internet or any server. Access to sync is protected by your
   device lock.
